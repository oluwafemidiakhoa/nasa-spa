# Gaia Observatory v1.0 RC1: protected cloud preview

The preview adds Mission Control and the dynamic Earth workspace without changing the original mission trainer, root routes, scientific algorithms or existing data. APOD and DONKI buttons call existing same-origin API endpoints. No automatic refresh, new paid service, database, or additional package dependency is introduced. APOD displays only returned title/date and fallback status; DONKI counts returned records. Neither validates source authenticity or coverage. FIRMS, JPL and Earthdata are not integrated.

Earth retrieval sends only start date, end date and category to a fixed NASA EONET endpoint via the Vercel function. Only the preview environment is enabled, with a 12-second upstream timeout, redirect rejection, a 2 MB source cap, a 200-event limit, and 1-30 calendar dates. No coordinates are sent by the workspace; do not publish private coordinates in downloaded evidence. Browser screening preserves exact source bytes, uses the existing v0.5 bundle schema, and replays the existing JavaScript method. No independent Python execution is performed by the browser. No match does not establish safety; a returned event point is not a hazard footprint. Coverage and source authenticity remain unestablished.

## Preview test

Sign in to the existing Vercel protected preview, open mission-control.html, then workspace.html. Load the synthetic example (three facilities, two with matches) first. Next use the default historical dates and city centers, or select recent complete UTC dates. Retrieve NASA data, select locations, inspect the plot and download the evidence bundle. Import the previously saved California bundle using the optional retained digest. Change inputs and check stale results clear. Check that APOD and DONKI controls either return source data or visibly report failure without substituting fabricated data. Test narrow/mobile layout and keyboard navigation.

For independent verification in a trusted local checkout of the matching source, run `python scripts/earth_evidence.py verify DOWNLOADED.json --expected-sha256 DIGEST` using a separately retained digest. A new browser-generated bundle requires an actual Python replay before claiming cross-runtime agreement.

Local targeted tests: `node --test tests/cloud-eonet.test.cjs tests/cloud-workspace.test.mjs tests/mission-control.test.mjs`. All 12 passed on Node 22.16.0 with controlled responses.
