# Gaia research assistant v0.9

## Fixed method contract

This is a deterministic evidence question interface, not a language model, general chatbot, predictor or safety service. Input is the original v0.5 evidence bundle; the browser recomputes v0.7 history and v0.8 screening, not a separately supplied analysis report. Accept only printable ASCII queries of 1-160 characters, case-sensitive, exact grammar: `summary`, `explain FACILITY-ID`, `day FACILITY-ID YYYY-MM-DD`, `provenance`, `limits`. No trimming, inferred intent or fuzzy matching. Unknown commands or unknown facilities/dates abstain with no data facts; screening abstentions include the screening record as evidence. Invalid input or bundle rejects. Use the declared fixture kind, coverage unknown, source unauthenticated and scientific validity not established in every answer. No risk, future event, causal, or safety conclusion is supported.

Each answer binds the original bundle/source SHA-256 and exact query. Facts contain a label, report type (`history` or `screening`), JSON pointer and exact value from the independently reproducible intermediate report. Summary lists each facility ID and status, explain includes the facility's screening record and rule, day includes a selected UTC row, provenance lists source identity and time bounds. Limits and unsupported/missing-entity abstentions have no data facts. Screening abstentions retain the actual screening record and policy. Facts are selected from computed records, not trusted from user-supplied reports. Answer text is fixed by status; no arbitrary source text becomes a command. All UI text is rendered as text, never HTML. Exported JSON is locally reproducible; an independent Python verifier recomputes history, screening and every answer field including pointers, with the original bundle and a separately supplied exact query. Optional independently retained bundle SHA-256 checks complete replacement; neither replay nor hash authenticates the source. Browser checks are same-method only. No new network calls, API keys, storage, dependencies or paid services. Do not publish private input coordinates or answers.

Acceptance: short synthetic bundle abstains from anomaly inference but supports factual day summaries; manufactured 20-day fixture explains one above-baseline facility and two not above; reject unsupported safety and forecast requests, unknown facility/day, malformed queries, altered reports/citations, query substitution, and wrong bundle digest. The software fixture is known and synthetic, not a prospective empirical evaluation. No claim of AI model performance.

## Use

Serve the repository with `python -m http.server 8000`; visit `http://localhost:8000/research.html`. Load the short synthetic example or import a bundle generated by `python scripts/anomaly_demo.py NEW_BUNDLE.json`. Ask a supported question and export JSON. Independently replay with `python scripts/verify_research_answer.py BUNDLE.json ANSWER.json --query "explain EXAMPLE-A" --expected-sha256 DIGEST` (digest optional, query required). Run `node --test tests/research.test.mjs` and `python -m unittest discover -s tests -p 'test_research_answer.py' -v`.
