# Earth Intelligence point screen v0.2

Scope: deterministic proximity screening, not prediction, hazard footprints, or evidence of actual exposure/damage. NASA EONET v3 event schema: https://eonet.gsfc.nasa.gov/docs/v3 . Input is a saved JSON snapshot or an explicitly synthetic fixture; authenticity and completeness are unknown. No network calls to NASA are made by this pilot.

Method locked before tests: use a single supplied facility coordinate, an explicit UTC as-of timestamp, a 1-720 hour lookback, and 1-1000 km radius. Include point observations in the closed interval [as-of minus lookback, as-of]. Compute spherical great-circle distance in km (mean Earth radius 6371.0088 km), use unrounded distance for the inclusive threshold, report the closest in-window point per matching event, break ties by time then coordinates, sort by distance then event ID. Longitude first, latitude second. Exclude non-point geometries and out-of-window observations and count both; reject malformed point observations, timestamps and duplicate event IDs rather than hiding errors. No match is not evidence of safety. Missing/unsupported geometry means incomplete coverage. A synthetic facility and synthetic observations support software verification only. No statistical or causal inference. Negative checks include invalid coordinates, dates, duplicate IDs, future/stale points, polygons, antimeridian and no-data outcomes. Hash exact snapshot bytes; a digest is not a signature or source authentication. Retain original bytes and the report for replay. Local method hash is not a trusted timestamp. Stop after local tests and one branch commit; no paid resources or production release.
